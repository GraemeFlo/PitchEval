# PitchEval

A referee evaluation and match‑logging web app for US Soccer Referee Coaches.

**Live app:** https://graemeflo.github.io/PitchEval/

Open the link on a phone or computer browser. On iPhone/iPad you can tap **Share → Add to Home Screen** to use it like an installed app. All data is stored locally on the device (the native iOS app additionally backs match data up via iCloud, syncing across a coach's own devices — this web version stores locally only).

## Features
- Live match clock, score, and per-team foul tracking, with Match Format settings (half length, extra time, kicks from the mark)
- Event logging: fouls, cards, offsides, goals, penalty kicks — with structured decision-chains (e.g. a reckless foul opens a Yellow Card form automatically)
- Critical Match Incident (CMI) and Critical Referee Error (CRE) records
- Optional photo and voice-note attachments on any event
- Grade-based referee ratings (Grassroots → FIFA) with automatic overall scoring
- AI-assisted coaching feedback, editable and translatable
- Match Library — save, browse, and review past matches, with performance trend tracking for each official over time
- Season/calendar view for upcoming assigned matches
- Full match log export (editable text file) and manual data backup/restore
- Accessibility: Large Text and High Contrast display modes

## Native iOS app
The App Store version of PitchEval adds native-only capabilities not available in this web version: iCloud sync across a coach's devices, on-device video attachments, and a Live Activity / Dynamic Island showing the running match clock and score on the Lock Screen.
